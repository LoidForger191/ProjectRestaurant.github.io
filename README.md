# Aster & Olive

A responsive Mediterranean restaurant website built with React and Vite.

## Run locally

```sh
npm ci
npm run dev
```

Create a production build with `npm run build`. The generated static site is written to `dist/`.

## Deployment

The GitHub Actions workflow in `.github/workflows/pages.yml` builds the site and deploys it to GitHub Pages when changes are pushed to `main`. Enable GitHub Pages for the repository with **GitHub Actions** as the build and deployment source.
